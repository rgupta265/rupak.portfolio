## 🚀 Running Locally

You can run the portfolio locally using any static web server:

### Option 1: Python
```bash
# Python 3.x
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Node.js (via `npx serve`)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Deployment

The site is 100% static and ready to deploy on:
- **GitHub Pages**: Go to **Settings** → **Pages** → select branch `new_portfolio` (or `main`) → root folder `/`.
- **Vercel**: Import this GitHub repository or deploy via `vercel deploy`.
- **Netlify**: Connect your GitHub repository and set publish directory to `./`.
